# turtle_draw
program dijalankan menggunakan timer sebagai acuan untuk gerakan robot. setiap 500ms robot akan menukar kegiatan dari berputar saja (kecepatan linear 0) atau bergerak dan berputar (memiliki kecepatan linear dan kecepatan angular). Robot akan berhenti bergerak setelah melakukan 16 kali pertukaran kegiatan.
