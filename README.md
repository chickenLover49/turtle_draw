# turtle_draw
program dijalankan menggunakan timer sebagai acuan untuk gerakan robot. setiap 500ms robot akan menukar kegiatan dari berputar saja (tidak memiliki kecepatan linear tetapi memiliki kecepatan anguler) atau bergerak dan berputar (memiliki kecepatan linear dan kecepatan angular). Robot akan berhenti bergerak setelah melakukan 16 kali pertukaran kegiatan.
